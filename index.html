# PS_Dev Branch The `ps_dev` branch is used as a development branch for the PS DevOps project. It contains the latest development changes and updates related to the solution, automation scripts, Jenkins pipeline, Terraform, and Ansible configurations. Changes are generally developed and tested in this branch before they are promoted or merged into the appropriate production/release branch. The `ps_dev` branch helps the team validate new changes and ensure that the pipeline and deployment process are working correctly before making them available in production.
